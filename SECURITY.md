# Security Policy

## Supported Versions

We issue security patches and updates for the following active branches:

| Version | Supported |
| ------- | ------------------ |
| 1.0.x (Main / Monad Testnet) | :white_check_mark: |
| < 1.0.0 | :x: |

---

## Reporting a Vulnerability

We take the security of **Vera Protocol** smart contracts, SDK, and dApp seriously.

If you discover a security vulnerability, please **do not** open a public issue. Instead, report it responsibly via one of the following methods:

1. **Email / Contact**: Send a private disclosure email to the maintainers or team leadership.
2. **Private Issue**: Request a security contact directly through maintainers.

### Please Include:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Potential impact of the vulnerability (e.g., unauthorized escrow payout release, signature bypass, state manipulation).

---

## Disclosure & Response Timeline

- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will evaluate the report and provide a status update within **5 business days**.
- **Fix & Disclosure**: Once a fix is verified and deployed, we will issue a security advisory and acknowledge your contribution (unless you request anonymity).
